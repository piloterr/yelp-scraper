# Yelp Scraper API – code examples

Examples for every Yelp endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/business.sh`](curl/business.sh) | `bash business.sh` |
| cURL (Bash) | [`curl/reviews.sh`](curl/reviews.sh) | `bash reviews.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
